# CDD Inventory — Support

Support page and ticket tracker for the **CDD Inventory** app (iOS and Android).

- **Support page:** https://xaviersvk.github.io/cdd-inventory-support/
- **Open a ticket:** [Issues → New issue](https://github.com/xaviersvk/cdd-inventory-support/issues/new/choose)
  (bug report, feature request or question)
- **Confidential matters:** matusdrexler@gmail.com
- **Privacy policy:** https://xaviersvk.github.io/cdd-inventory-privacy/

> Tickets are public. Never post API tokens, vault IDs or confidential sample data.

## Ticket workflow

| Label | Meaning |
|---|---|
| `needs-triage` | New, not yet reviewed |
| `bug` / `enhancement` / `question` | Ticket type (set by the template) |
| `ios` / `android` | Affected platform (set during triage) |
| `confirmed` | Reproduced, will be fixed |
| `fixed-in-next-release` | Fix merged, waiting for a store release |

Close the ticket when the fix ships, naming the app version that contains it.
